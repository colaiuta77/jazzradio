# Jazz Radio

BookOasis에서 책을 읽으며 인터넷 재즈 라디오를 들을 수 있는 사이드바 플러그인입니다.

**버전 · v1.8.1**

![Jazz Radio 화면](docs/screenshot.png?v=1.8.1)

## 주요 기능

- RelaxingJazz, Radio Swiss Jazz, Jazz24의 3개 방송국.
- 재생·일시정지, 볼륨 조절, 현재 곡과 앨범 표지 표시.
- 다른 메뉴로 이동해도 재생을 유지하는 미니 플레이어. 위치 이동과 모바일 접기 지원.
- 8가지 시각화. Live Spectrum, Mirror Bars, Line Spectrum, Waveform, Vintage Amp, Amber Ribbon, Jazz Constellation, Particle Dance.
- 빈티지 앰프의 좌우 VU 바늘과 재생 상태에 따른 LED·전원 스위치.
- 마지막 방송국, 볼륨, 시각화 모드, 미니 플레이어 위치 저장.

시각화 영역을 누르면 모드가 바뀝니다. 앰프의 전원 스위치는 재생·일시정지로 동작합니다. 메뉴 이동 후 재생은 같은 페이지 안에서 유지되며, 새로고침 후 자동 재생하지 않습니다.

Jazz Constellation은 초록 연결망과 흰 발광 입자, Particle Dance는 연결선 없는 파스텔 보케 입자를 표시합니다. 음악의 주파수에 따라 입자 크기와 밝기가 변하고, 입자 구름은 천천히 흐릅니다. 본문과 미니 플레이어에 공통 적용되며 화면 크기에 따라 입자 수를 조절합니다. [초록 연결망 프리셋](https://vizz.fm/app/?preset=Y29uZmlnLTE3NzAxNDYyOTMzNTYtNjg0)과 [파스텔 입자 프리셋](https://vizz.fm/app/?preset=Y29uZmlnLTE3NzAxNjA0MjczNzgtNTUw)을 참고해 Canvas로 구현했습니다.

BookOasis v2.8.4의 플러그인 베이스 클래스·데이터 API·카테고리 UI 번들 계약을 확인했습니다. 방송 중계 응답은 BookOasis 코어 `eefecdd`의 실제 데이터 API 함수로 추가 검사했습니다. 운영 서버에서의 통합 검증은 별도입니다.

## LP 노이즈

회전하는 레코드 버튼을 누르면 LP 노이즈를 켜거나 끕니다. 켜면 금색 테두리와 0~100% 강도 슬라이더가 나타납니다. 본문과 미니 플레이어에 동일하게 적용되며 브라우저에 설정을 저장합니다. 기본은 꺼짐, 강도는 30%입니다. 강도 슬라이더는 켜거나 마지막으로 강도를 조절한 뒤 10초 후 숨겨집니다. 노이즈는 계속 재생되며, 껐다 켜면 슬라이더가 다시 나타납니다. 재생·볼륨 상태를 따라 동작하며 일시정지·버퍼링·종료 시 멈춥니다.

노이즈는 브라우저에서 합성한 히스와 랜덤 크랙입니다. 20초 분량을 반복하며 다시 시작할 때 새로 생성합니다. iOS 실기기에서 이 기능은 아직 검증하지 않았습니다.

## 설치

이 저장소의 실행 파일을 BookOasis의 `plugins/metadata/jazzradio/`에 배치합니다.

```text
plugins/metadata/jazzradio/
├── __init__.py
├── jazzradio.py
├── index.html
├── style.css
├── script.js
├── pcm_probe.html
├── vendor/              # iOS 재생·분석 디코더와 라이선스 고지
└── VERSION
```

BookOasis에서 플러그인을 로드·활성화한 후 사이드바의 **Jazz Radio**를 선택합니다. 기존 설치를 교체했다면 `vendor` 폴더를 포함해 복사한 뒤 BookOasis 백엔드 또는 컨테이너를 재시작하고 브라우저를 새로고침하세요. 하단 **재생 진단**을 눌러 앱/서버 버전이 모두 1.8.1인지 확인합니다. 현재 플러그인 자체의 자동 업데이트 주소는 설정되어 있지 않습니다.

## iOS Safari 재생과 제약사항

- **iPhone·iPad만 단일 PCM 방식**을 사용합니다. 동일 사이트의 서버 중계로 받은 방송을 브라우저에서 디코딩하고, 같은 PCM과 출력 시계로 음악·시각화를 처리합니다. PC·안드로이드는 기존 방송 직접 재생과 Web Audio 분석을 사용합니다.
- **iPhone 실기기에서 무음 모드 음악 출력, 거의 실시간인 시각화 반응, 정상적인 채널 전환을 사용자 확인했습니다.** 모든 iOS 버전·기기에서의 동작을 보장하는 검증은 아닙니다.
- 지원 기기에서는 재생 전에 Audio Session을 `playback`으로 지정합니다. API 미지원 기기(예: iOS 16 이하)나 설정이 거부된 환경에서는 무음 모드를 해제해야 소리가 들릴 수 있습니다. [WebKit 공식 안내](https://bugs.webkit.org/show_bug.cgi?id=251532).
- 첫 재생에는 연결·디코딩과 약 0.75초의 출력 버퍼 준비 시간이 필요합니다. 일시정지·채널 변경 시 이전 연결과 예약된 소리를 정리하고 현재 방송으로 다시 연결합니다. 네트워크가 느리면 버퍼링할 수 있습니다.
- **잠금 화면·다른 앱 전환·장시간 재생은 추가 확인이 필요합니다.** iOS가 오디오 Context를 중단하면 재생을 일시정지합니다. 복귀 후 재생 버튼을 눌러주세요. 기기 볼륨 버튼으로 음량을 조절합니다.
- 하단 **재생 진단**을 펼치면 버전·재생 상태·분석값과 오류를 볼 수 있습니다. `단일 PCM 재생`, `Context running`, 지원 기기의 `Audio Session playback`은 정상 표시입니다. 디코더·연결 오류 또는 12초 데이터 대기 초과 시 오류를 표시하며, 재생 버튼으로 다시 시도할 수 있습니다.
- LP 노이즈는 음악과 같은 Context를 사용하고 일시정지·버퍼링 때 멈춥니다. 시각화에는 LP 소음을 섞지 않습니다. 별도 **5초 PCM 진단**은 일반 라디오를 멈춘 뒤 사용하세요.
