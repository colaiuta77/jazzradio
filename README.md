# Jazz Radio

BookOasis에서 책을 읽으며 인터넷 재즈 라디오를 들을 수 있는 사이드바 플러그인입니다.

**버전 · v1.12.0**

![Jazz Radio 실제 사용 화면](docs/screenshot.png?v=1.12.0)

## 주요 기능

- **3개 방송국**. RelaxingJazz, Radio Swiss Jazz, Jazz24를 화살표나 채널 점 버튼으로 선택합니다.
- **재생과 곡 정보**. 재생·일시정지, 볼륨·음소거, 현재 곡과 앨범 커버를 표시합니다. 더 알아보기에서 앨범 정보, 음악 서비스와 공식 홈페이지 링크를 확인합니다.
- **다른 메뉴에서도 재생**. 같은 페이지 안에서 메뉴를 이동하면 하단 도크로 재생을 이어갑니다. 도크의 커버·곡 정보를 누르면 Jazz Radio 홈으로 돌아옵니다. 도크 접기를 지원하며, 새로고침 후에는 자동 재생하지 않습니다.
- **8가지 시각화**. Live Spectrum, Mirror Bars, Line Spectrum, Waveform, Vintage Amp, Amber Ribbon, Jazz Constellation, Particle Dance를 제공합니다. 시각화 영역이나 모드 이름을 눌러 전환하며, 빈티지 앰프의 전원 스위치는 재생·일시정지로 동작합니다.
- **색상과 화면 설정**. BookOasis의 밝은·어두운 테마에 맞춰 화면을 전환합니다. 색상 프리셋·직접 선택, 0–100% 색감 강도와 모바일·태블릿 하단바의 시각화 위치를 설정합니다.
- **턴테이블과 LP 노이즈**. 앨범 커버와 회전하는 턴테이블을 전환하고, 레코드 버튼으로 LP 노이즈를 켜거나 끕니다.

마지막 방송국, 음악 볼륨, 시각화 모드, 색상·강도, 하단바 시각화 위치와 LP 설정은 현재 브라우저에 저장됩니다.

## 설치

다음 실행 파일과 폴더를 BookOasis의 `plugins/metadata/jazzradio/`에 배치합니다.

```text
plugins/metadata/jazzradio/
├── __init__.py
├── jazzradio.py
├── index.html
├── style.css
├── script.js
├── pcm_probe.html
├── assets/              # 턴테이블 본체와 LP 이미지
├── vendor/              # iOS 디코더와 라이선스 고지
└── VERSION
```

BookOasis에서 플러그인을 로드·활성화한 후 사이드바의 **Jazz Radio**를 선택합니다. 업데이트할 때도 `assets`와 `vendor`를 함께 복사한 뒤 BookOasis 백엔드 또는 컨테이너를 재시작하고 브라우저를 새로고침하세요. **더 알아보기 → 재생 진단**에서 앱·서버 버전이 모두 **1.12.0**인지 확인할 수 있습니다. 플러그인 자체의 자동 업데이트 주소는 설정되어 있지 않습니다.

자체 배경 설정은 BookOasis 코어 **3.1.1**의 설정·인증 처리와 SQLite 설정 저장소를 연결해 확인했습니다. 실제 Unsplash API 인증 연결과 MariaDB 환경은 별도로 확인해야 합니다.

## 시각화와 화면 설정

컨트롤 오른쪽의 시각화 버튼으로 영역을 접고 펼칩니다. 기본은 켜짐이며 **메인 화면과 하단 도크가 같은 켜기 상태를 공유**합니다. 시각화를 꺼도 음악은 계속 재생됩니다. 도크를 접으면 시각화 패널도 함께 접힙니다.

**더 알아보기 → 설정**에서 기본·스카이·민트·라벤더·로즈·골드·실버 또는 원하는 색상을 선택합니다. 버튼·재생바·NOW PLAYING과 Live Spectrum, Mirror Bars, Line Spectrum, Waveform, Amber Ribbon에 같은 색상 계열을 적용합니다. 색감 강도를 낮추면 채도가 줄어들며, 기본을 선택하면 색상과 강도가 초기화됩니다.

모바일과 태블릿은 세로 플레이어를 사용하고 채널 선택을 메인 플레이어 위에 배치합니다. **폭 800px 이하 또는 폭 1200px 이하의 터치 기기**에 이 배치를 적용하므로 넓은 iPad 화면도 지원합니다. 하단바 시각화는 설정에서 재생창 위·아래를 선택할 수 있습니다. 540px 이하에서는 하단바의 곡 정보와 컨트롤을 두 줄로 표시합니다.

## 사진 배경

기본 내장 API 키는 없습니다. 배경 선택 우선순위는 **Detail Studio의 저장된 키·사용 동의 → Jazz Radio 자체 키·사용 동의 → 고정 기본 사진**입니다. Detail Studio가 없어도 자체 키를 등록하면 Unsplash 공식 API에서 `jazz`로 검색한 가로 사진을 무작위로 표시합니다.

**더 알아보기 → 설정 → 배경 사진**에서 현재 사용 원본을 확인합니다. 기본 비밀번호를 변경한 관리자는 Unsplash **Access Key**와 사용 동의를 저장하거나 자체 설정을 삭제할 수 있고, 일반 사용자는 사용 원본만 볼 수 있습니다. 키 입력칸을 비워 저장하면 기존 자체 키를 유지합니다. 삭제는 Jazz Radio 자체 키·동의만 제거하며, Detail Studio 설정이 우선 적용되는 동안 자체 설정은 대기합니다.

키는 BookOasis 서버의 플러그인 설정 DB에 저장합니다. **설정 조회 응답에 키 원문을 반환하지 않으며 브라우저 저장소에도 보관하지 않습니다.**

사진은 서버에서 3시간 캐시하며, 시간이 지난 뒤 다음 화면 조회 때 새 사진을 선택합니다. 열린 화면에서 자동 교체하지는 않습니다. 사진 출처 옆 **사진 아이콘**으로 즉시 바꿀 수 있고, 연속 수동 변경은 1분 간격입니다. 키·동의·사용 원본 변경은 다음 사진 요청에 반영됩니다.

API 요청 실패 시 15분 동안 재요청을 제한하고 같은 원본에서 받은 이전 사진을 유지합니다. 새 원본에서 사진을 가져오지 못했거나 설정이 없으면 고정 기본 사진을 사용합니다. **기본 사진도 Unsplash CDN에 연결할 수 있어야 표시됩니다.** 사진가와 Unsplash 출처 링크는 배경 하단에 표시합니다.

## 곡 정보와 진행률

앨범 커버·앨범명·장르·발매일·수록곡 길이는 방송 곡명과 매칭한 외부 자료입니다. **iTunes를 우선 사용**하고 커버·앨범명·곡 길이·발매일이 부족하면 **MusicBrainz + Cover Art Archive**로 빈 항목만 보완합니다. 추가 API 키는 필요하지 않으며, 백그라운드 조회가 끝나면 다음 곡 정보 갱신에 반영됩니다.

곡명과 전체 아티스트 이름이 일치하고 녹음·공식 발매 그룹을 하나로 식별할 때만 보완합니다. 다른 판본을 구분할 수 없거나 승인된 앞표지가 없으면 기존 커버 또는 턴테이블을 유지합니다. 매칭 자료는 실제 방송 판본과 다를 수 있으며, 더 알아보기의 자료 링크에서 MusicBrainz·CAA 출처를 확인할 수 있습니다. 커버 저작권은 각 권리자에게 있습니다.

Apple Music은 매칭된 곡 페이지를 우선 연결하고, Spotify·YouTube Music은 현재 가수·곡명 검색 결과로 연결합니다. **Official website**는 MusicBrainz에 등록된 아티스트를 명확하게 식별할 때만 표시합니다. 링크는 등록 도메인의 첫 화면으로 연결하며 하위 경로·쿼리·해시는 제거합니다. 동명이인·정보 없음·조회 실패 시 숨기며, 실제 사이트 운영 여부를 보장하지 않습니다.

**진행률은 실제 방송 위치가 아닌 추정값**입니다. 연속 재생 중 곡 변경을 감지한 시점과 매칭된 수록곡 길이로 계산하며, 메타데이터 갱신 간격·방송 버퍼·다른 녹음판에 따라 오차가 생깁니다. 첫 접속, 일시정지 후 재개, 채널 전환 또는 곡 정보가 오래되거나 누락된 경우에는 청취 경과 시간을 표시합니다. 곡 길이까지만 진행한 뒤 다음 곡 확인을 기다리며, 정확한 남은 시간이나 곡 탐색은 지원하지 않습니다. 하단 도크는 추정 위치를 확인할 수 있을 때 상단 진행률 바를 표시합니다.

## 볼륨과 LP 노이즈

스피커 아이콘은 기존 음량을 보존하면서 음소거·해제를 전환합니다. PC·Android는 슬라이더로 음악 볼륨을 조절하며 조절한 음량 %를 2초간 표시합니다. **iOS 음악 볼륨은 기기 볼륨 버튼으로 조절**하고, 플러그인 스피커 버튼은 음악과 LP를 함께 음소거합니다.

메인 앨범 커버를 누르거나 Enter·Space를 누르면 커버와 턴테이블을 전환합니다. 커버가 없거나 이미지 로딩에 실패하면 턴테이블을 표시합니다. LP는 실제 음악이 재생되는 동안 회전하고 일시정지·버퍼링 때 멈춥니다. 동작 줄이기 설정에서는 회전하지 않습니다. 하단 도크의 커버는 홈 이동 버튼으로 동작합니다.

레코드 버튼으로 LP 노이즈를 켜면 **공용 볼륨 슬라이더가 10초간 LP 강도 조절로 전환**됩니다. 강도는 0–100%이며 마지막 조절 후 10초가 지나면 음악 볼륨으로 돌아옵니다. LP는 설정한 강도로 계속 재생되며, 다시 조절하려면 레코드 버튼을 껐다 켭니다. 음악 볼륨과 LP 강도는 각각 저장됩니다. iOS에서도 LP 조절 중에는 슬라이더가 나타나고, 시간이 지나면 기기 볼륨 안내로 돌아갑니다.

LP 노이즈는 기본 꺼짐·강도 30%이며 브라우저에서 합성한 히스와 크랙을 사용합니다. 일시정지·버퍼링·음소거 때 멈추고 시각화 분석에는 섞이지 않습니다. iOS 실기기의 LP 노이즈는 아직 검증하지 않았습니다.

## iOS Safari 재생과 제약사항

- **iPhone·iPad는 단일 PCM 방식**으로 재생합니다. 서버 중계로 받은 방송을 브라우저에서 디코딩하고 같은 PCM과 출력 시계로 음악·시각화를 처리합니다. PC·Android는 방송 직접 재생과 Web Audio 분석을 사용합니다.
- **iPhone 실기기에서 무음 모드 음악 출력, 거의 실시간인 시각화 반응과 정상적인 채널 전환을 사용자 확인했습니다.** 모든 iOS 버전·기기를 검증한 것은 아닙니다.
- 지원 환경에서는 재생 전에 Audio Session을 `playback`으로 지정합니다. API 미지원 또는 설정이 거부된 환경에서는 무음 모드를 해제해야 소리가 들릴 수 있습니다.
- 첫 재생에는 연결·디코딩·출력 버퍼 준비 시간이 필요합니다. 일시정지·채널 전환 시 이전 연결과 예약된 소리를 정리하며, 느린 네트워크에서는 버퍼링할 수 있습니다.
- **잠금 화면·다른 앱 전환·장시간 재생은 추가 확인이 필요합니다.** iOS가 오디오 처리를 중단하면 일시정지하므로 복귀 후 재생 버튼을 눌러주세요.
- **더 알아보기 → 재생 진단**에서 버전·재생 상태·분석값·오류를 확인할 수 있습니다. `단일 PCM 재생`, `Context running`, 지원 환경의 `Audio Session playback`은 정상 표시입니다. 연결 오류나 12초 데이터 대기 초과 시 재생 버튼으로 다시 시도하세요. 별도 **5초 PCM 진단**은 일반 라디오를 멈춘 뒤 사용합니다.

iOS 디코더는 `mpg123-decoder 1.0.3`을 사용합니다. 출처·라이선스·빌드 방법은 [제3자 고지](vendor/THIRD_PARTY_NOTICES.txt), 버전별 변경은 [변경 내역](CHANGELOG.md)을 참고하세요.
